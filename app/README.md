# JPNarabu App

Flutter application scaffold for the JPNarabu Japanese-learning app.

## Requirements

- Flutter stable
- Dart included with Flutter
- Android SDK for Android builds
- macOS with Xcode for iOS builds

## Run

From this directory:

```bash
flutter pub get
flutter run
```

## Validate

```bash
flutter analyze
flutter test
```

The app is currently the default Flutter template. Product features are
implemented in later stages described in the repository's `issue.md`.
